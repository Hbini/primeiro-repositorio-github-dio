# 🤝 Guia de Contribuição

Agradecemos seu interesse em contribuir para este projeto! Este documento fornece diretrizes para garantir uma colaboração tranquila e produtiva.

## 📋 Código de Conduta

Todos os contribuidores devem:
- Ser respeitosos e inclusivos
- Acolher feedback construtivo
- Focar em questões e não em pessoas
- Manter discussões profissionais e cordiais

## 🚀 Como Começar

### 1. Fork e Clone
```bash
git clone https://github.com/seu-usuario/primeiro-repositorio-github-dio.git
cd primeiro-repositorio-github-dio
```

### 2. Criar uma Branch
```bash
git checkout -b feature/sua-contribuicao
```

### 3. Fazer suas Alterações
- Faça alterações lógicas e bem focadas
- Mantenha a consistência com o código existente
- Adicione comentários onde necessário

### 4. Commit
```bash
git add .
git commit -m "Descrição clara das mudanças"
```

### 5. Push
```bash
git push origin feature/sua-contribuicao
```

### 6. Pull Request
- Descreva as mudanças claramente
- Referência problemas relacionados se houver
- Aguarde revisão dos mantenedores

## ✅ Padrões de Código

- Use nomes descritivos em português ou inglês (de forma consistente)
- Mantenha linhas com menos de 80 caracteres quando possível
- Adicione comentários para lógica complexa
- Teste suas mudanças antes de enviar

## 🐛 Reportando Bugs

Se encontrar um bug, abra uma issue descrevendo:
1. O comportamento esperado
2. O comportamento atual
3. Passos para reproduzir
4. Seu ambiente (SO, versão, etc.)

## 💡 Sugerindo Melhorias

Sugestões de melhorias são bem-vindas! Descreva:
1. O problema que a melhoria resolve
2. A solução proposta
3. Benefícios da implementação

## 📞 Precisa de Ajuda?

- Abra uma discussão para perguntas gerais
- Verifique issues existentes antes de criar uma nova
- Leia a documentação do README

Obrigado por contribuir! 🎉
